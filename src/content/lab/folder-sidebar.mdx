A tiny experiment: make the sidebar feel like a file tree without
shipping a heavy disclosure component.

<FolderDemo />

## What it does

- Each section renders as a folder icon that swaps between `Folder` and
  `FolderOpen` from Lucide.
- The icon swap is a quick rotate-and-fade, not a hard cut.
- Children expand using a `grid-template-rows: 0fr → 1fr` trick so the
  reveal animates without measuring height in JS.

## Why it is in the lab

Because it is a detail, not a product. It either delights the first
time you click it or it disappears into the background — both are fine.
